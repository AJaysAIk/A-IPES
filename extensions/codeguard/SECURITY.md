# Security and responsible use

This is an exploratory defensive evaluation harness, not a production scanner. Intentionally vulnerable examples are text fixtures, must not be deployed, and are never executed by the harness. Safe examples have narrow documented assumptions.

For an unexpected vulnerability in the harness itself, use GitHub's private vulnerability reporting if available on the repository, or contact the maintainer privately via https://linkedin.com/in/ajay-kummara to arrange disclosure. Do not publish credentials, personal data, or operational exploit details in public issues. Ordinary bugs and documentation corrections can be filed as issues. No response-time or supported-version guarantee is offered.

Future model adapters must treat source comments and model outputs as untrusted, avoid executing suggested code, and obtain authorization before sending private code to an external provider.
